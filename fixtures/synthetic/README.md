# Synthetic Aven fixtures

This directory is the public location for deliberately invented test documents and structured examples.

Every fixture must:

- identify Aven as a demo for the fictional insurer Meridian Health Assurance;
- use only fictional people, hospitals, identifiers, addresses, clinical facts, policies, and amounts;
- avoid copied wording, images, identifiers, or metadata from private reference PDFs;
- state its scenario and expected behavior clearly enough to review;
- contain no API key, password, token, connection string, or local environment value.

Private source documents and derivatives belong under `private/`, never here. If the origin or safety of a file is uncertain, treat it as private until reviewed.
